# astudio-1c — агент для 1С:Предприятия 8.3 в Claude Code

[English](README.md) · **Русский**

Автор: **astudio.one** — [astudio.one](https://astudio.one) · Лицензия: MIT · Версия 1.0.0

Плагин превращает агента во внимательного архитектора 1С: конфигурацию он читает из XML-выгрузки и не выдумывает имена, запросы и код на встроенном языке пишет по стандартам разработки ИТС, собирает внешние обработки и отчёты, типовые конфигурации меняет только расширениями и объясняет пользователю простыми словами, откуда в базе взялась цифра. Рабочие базы только читаются; изменения делаются в тестовой копии после согласия пользователя.

## Что умеет

- Режимы работы: объяснить, запрос, быстрая правка, полный цикл, обработка, расширение, ревью — с переходом к полному циклу, если затронуты проведение, транзакции или права
- Индекс конфигурации из XML-выгрузки Конфигуратора или EDT: объекты, реквизиты, табличные части, движения — никаких выдуманных имён
- Правила языка запросов со ссылками на стандарты ИТС: условия в параметрах виртуальных таблиц через И, индексированные временные таблицы, никаких запросов в цикле и соединений с вложенными запросами
- Шаблоны кода: клиент и сервер, асинхронные диалоги, транзакции, управляемые блокировки, проведение с контролем остатков, журнал регистрации, безопасность
- Внешние обработки и отчёты (.epf/.erf) с регистрацией в БСП, сборка и разборка пакетными командами Конфигуратора
- Расширения с &Перед/&После/&ИзменениеИКонтроль вместо правки объектов на поддержке
- Разбор остатков, долгов и цифр отчётов, журнала регистрации и прав простыми словами — только чтение

## Установка

В Claude Code:

```
/plugin marketplace add whoamnesia/astudio-1c
/plugin install astudio-1c@astudio-1c
```

Перезапустите Claude Code. Навыки появятся в меню `/` как `astudio-1c:astudio-1c` …

Установка на закреплённом коммите (так делает aiocenter.ru): склонируйте репозиторий, перейдите на опубликованный коммит и выполните `/plugin marketplace add ~/.aiocenter/packages/astudio-1c`.

Другие агенты (Cursor, Codex, Gemini CLI): каждый навык — обычный `skills/<name>/SKILL.md` со справочниками; укажите агенту папку или скопируйте её в правила агента.

## Навыки

| Навык | Что делает |
|---|---|
| `astudio-1c` | Главный навык: выбор режима, факты из метаданных, правила безопасности, результат |
| `1c-queries` | Запросы и СКД по стандартам ИТС, с проверкой |
| `1c-code` | Модули на встроенном языке: клиент-сервер, транзакции, блокировки, проведение |
| `1c-metadata` | Выгрузка, индекс и чтение метаданных конфигурации |
| `1c-processors` | Внешние обработки и отчёты, регистрация в БСП, сборка |
| `1c-extensions` | Расширения для конфигураций на поддержке |
| `1c-explain` | Объяснение остатков, сумм, проведения, журнала регистрации и прав пользователю |
| `1c-review` | Ревью кода по чек-листу ИТС |

## Инструменты

Python 3.9+, только стандартная библиотека. Читают то, что вы им передали, и ничего не записывают, если вы сами не перенаправите вывод.

| Скрипт | Назначение |
|---|---|
| `scripts/meta_index.py` | Индекс XML-выгрузки конфигурации: сводка, карточка объекта, поиск имени |
| `scripts/bsl_check.py` | Статическая проверка запросов и кода со ссылками на стандарты ИТС |
| `scripts/designer.py` | Пакетные команды Конфигуратора с защитой (одна команда за запуск, --test-base для изменений, скрытый пароль) |

## Безопасность

- Рабочие базы только читаются: запросы, без записи, проведения и удаления.
- designer.py не загружает конфигурацию и не обновляет базу без флага --test-base; одна пакетная команда за запуск.
- Объекты на поддержке напрямую не меняются, только расширениями.
- Учётные данные только из переменных окружения; персональные данные в отчётах маскируются; результаты запуска не выдумываются.
